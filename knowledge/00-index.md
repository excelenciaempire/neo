# Cheatsheet

## Cheatsheet

- [Ethical Hacking Cheatsheet](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet.md): Aquí encontrarás una guía completa y actualizada sobre técnicas y herramientas de hacking ético para ayudarte en tus ejercicios de pentesting y ciberseguridad.
- [Metodología OSSTMM](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/metodologia-osstmm.md): La metodología OSSTMM (Open Source Security Testing Methodology Manual) es una metodología de hacking ético que se utiliza para evaluar la seguridad de los sistemas de información y redes.
- [MITRE ATT\&CK](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/mitre-att-and-ck.md): MITRE ATT\&CK (Adversarial Tactics, Techniques, and Common Knowledge) es un framework de seguridad informática desarrollado por el MITRE Corporation.
- [Proceso de Pentesting](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/proceso-de-pentesting.md): En esta sección veremos el proceso que vamos a seguir a la hora de realizar un ejercicio de pentesting o hacking ético.
- [Instalación del entorno](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno.md): En esta sección veremos cómo instalar un entorno profesional de hacking con VMWare y Kali Linux, uno de los sistemas operativos más utilizados por hackers de todo el mundo.
- [Instalación de VMWare](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/instalacion-de-vmware.md): En esta sección veremos cómo instalar VMWare, uno de los mejores softwares de virtualización que nos permitirá instalar diversas máquinas virtuales, como Kali Linux.
- [Virtualizar Kali Linux](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/virtualizar-kali-linux.md): En esta sección veremos cómo virtualizar Kali Linux, uno de los sistemas operativos más utilizados por hackers de todo el mundo.
- [Personalización del entorno](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/personalizacion-del-entorno.md): Vamos a personalizar nuestro entorno Kali Linux  para hacer que sea más cómodo movernos por terminal y lanzar distintos ataques contra sistemas.
- [Máquinas Vulnerables](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/maquinas-vulnerables.md): En esta sección recogeré los pasos de instalación de diversas máquinas virtuales con las que podremos practicar distintas técnicas de hacking en entornos controlados:
- [Metasploitable 3](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/maquinas-vulnerables/metasploitable-3.md): Metasploitable 3 es un entorno vulnerable compuesto de 2 máquinas: Un Windows Server 2008 R2 y una máquina Ubuntu
- [VPLE](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/maquinas-vulnerables/vple.md): Vulnerable Pentesting Lab Environment (VPLE) es un entorno virtualizado diseñado específicamente para realizar pruebas de seguridad y evaluaciones de penetración en sistemas y aplicaciones.
- [Windows 11 Developer](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/instalacion-del-entorno/maquinas-vulnerables/windows-11-developer.md): Utilizaremos una máquina Windows 11 Developer para probar técnicas de evasión de antivirus y de hacking en entornos modernos, haciendo bypass del Windows Defender.
- [Organización y Notas](https://afsh4ck.gitbook.io/ethical-hacking-cheatsheet/introduccion/ethical-hacking-cheatsheet/organizacion-y-notas.md): Una organización de archivos estructurada nos permitirá ser más eficientes en nuestras auditorías y ejercicios de pentesting.
