
# AWS - Amazon Web Services

## <mark style="color:purple;">Introducción</mark>

AWS ofrece una amplia gama de servicios de infraestructura, plataforma y software, que incluyen:

### Almacenamiento en la nube:&#x20;

AWS ofrece servicios de almacenamiento escalable y seguro, como Amazon S3 y Amazon Glacier, que pueden ser utilizados para almacenar y recuperar datos a través de la web.

### Computación en la nube:&#x20;

AWS ofrece una variedad de servicios de computación en la nube, como Amazon EC2 y Amazon Lightsail, que permiten a los usuarios lanzar y administrar servidores virtuales en la nube.

### Bases de datos:&#x20;

AWS ofrece servicios de base de datos en la nube, como Amazon RDS y Amazon DynamoDB, que permiten a los usuarios almacenar, procesar y acceder a datos en la nube.

### Redes y entrega de contenido:&#x20;

AWS ofrece servicios de red y entrega de contenido, como Amazon Route 53 y Amazon CloudFront, que permiten a los usuarios administrar y optimizar el tráfico de red en la nube.

### Herramientas de desarrollo y administración:&#x20;

AWS ofrece herramientas y servicios para desarrolladores, como AWS CodeDeploy y AWS CloudFormation, que permiten a los usuarios implementar, administrar y escalar aplicaciones en la nube.
