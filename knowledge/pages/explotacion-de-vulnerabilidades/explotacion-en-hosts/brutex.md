Fuerza bruta automática contra todos los servicios corriendo en un host:

* Puertos abiertos
* Usuarios
* Passwords

### Instalación <a href="#user-content-install" id="user-content-install"></a>

```bash
git clone https://github.com/1N3/BruteX.git
cd BruteX
./install.sh
```

### Uso: <a href="#user-content-usage" id="user-content-usage"></a>

```bash
sudo brutex target <port>
```
