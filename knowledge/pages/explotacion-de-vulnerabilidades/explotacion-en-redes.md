
# Explotación en Redes

{% hint style="danger" %}
**Nota:** Este tipo de técnicas son muy invasivas, ya que vamos a ganar acceso a distintos sistemas, por lo que no podemos utilizar estas técnicas sin un consentimiento o aprobación por parte del objetivo
{% endhint %}

Los atacantes pueden explotar vulnerabilidades en redes para realizar diversas acciones maliciosas, como:

* Acceder a información confidencial, como datos personales, financieros o de propiedad intelectual.
* Interceptar y manipular el tráfico de red para obtener información o realizar ataques de phishing.
* Tomar el control de sistemas y dispositivos en la red para instalar malware o ransomware.
* Realizar ataques de denegación de servicio (DoS) para interrumpir el funcionamiento normal de la red o del servicio.

En las siguientes secciones veremos las técnicas y herramientas más utilizadas para la explotación de vulnerabilidades en redes.
