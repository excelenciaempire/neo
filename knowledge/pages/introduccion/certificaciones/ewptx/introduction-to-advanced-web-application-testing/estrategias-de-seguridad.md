
# Estrategias de seguridad

Antes de lanzarnos a explotar vulnerabilidades o configurar herramientas, es necesario comprender el *mapa* que guía todo el proceso de testing avanzado: las estrategias de seguridad. Esta sección sienta las bases metodológicas y conceptuales que utilizarás en el resto del manual. No se trata de teoría abstracta, sino de frameworks probados, estándares reconocidos y enfoques prácticos que separan una prueba amateur de una profesional.

A lo largo de los siguientes tres capítulos cubrirás:

* La **metodología** paso a paso de una prueba de penetración en aplicaciones web.
* El **OWASP Top 10**, el catálogo de riesgos más influyente del mundo del software.
* Las **pruebas de seguridad** como disciplina: tipos, herramientas y buenas prácticas.
