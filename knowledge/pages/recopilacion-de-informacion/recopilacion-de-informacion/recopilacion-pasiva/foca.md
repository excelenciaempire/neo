
# FOCA

## <mark style="color:purple;">Introducción</mark>

FOCA se utiliza para descubrir y recopilar información sobre una organización, como nombres de dominio, direcciones IP, servidores web, correos electrónicos, nombres de usuario y otra información relacionada con la seguridad de la red. La herramienta utiliza técnicas avanzadas de análisis de metadatos para recopilar esta información. Podemos subir archivos pdf, imágenes, etc... o escanear un dominio en busca de metadatos.
