
# Custom Firmwares

## <mark style="color:orange;">**¿Qué es un Custom Firmware?**</mark>

Un **custom firmware** para Flipper Zero es una versión modificada del software original que añade nuevas funcionalidades, desbloquea ciertas restricciones o mejora la experiencia del usuario. Estos firmwares permiten:

* Desbloquear funciones avanzadas.
* Mejorar la interfaz y usabilidad.
* Ampliar la compatibilidad con más protocolos y herramientas.
* Experimentar con nuevas funciones que no están en el firmware oficial.

## <mark style="color:orange;">**Instalando Momentum Firmware en Flipper Zero**</mark>

Momentum es considerado el mejor custom firmware para Flipper Zero debido a su enfoque en la estabilidad sin sacrificar las funciones avanzadas. Este firmware optimiza el rendimiento de la batería y cuenta con un soporte excelente de la comunidad, lo que garantiza una experiencia de usuario robusta y confiable.

Para instalarlo podemos seguir varios métodos como indica en su wiki:

{% embed url="<https://github.com/Next-Flip/Momentum-Firmware?tab=readme-ov-file#Install>" %}

{% hint style="warning" %}
Antes de instalar cualquier custom firmware es recomendable tener un backup del Flipper Zero.
{% endhint %}

### **Web Updater (Chrome)**

Para instalar el firmware Momentum en tu Flipper Zero, sigue estos pasos:

1. **Conecta tu Flipper Zero al ordenador:** Utiliza un cable USB tipo C que soporte transferencia de datos.
2. **Accede al sitio web de Momentum:** Visita [momentum-fw.dev](https://momentum-fw.dev/) y haz clic en el botón "Install". Importante acceder a través de Google Chrome, ya que es el navegador soportado para este tipo de instalación.
3. **Conecta tu dispositivo al instalador:** Sigue las indicaciones en pantalla para seleccionar y conectar tu Flipper Zero.

<figure><img src="/files/kcIVLKR0NZiUo2bWPMcl" alt=""><figcaption></figcaption></figure>

4. **Selecciona la versión del firmware:** Elige entre la versión "Release" (estable) o "Development" (experimental).

{% hint style="success" %}
Se recomienda instalar siempre la versión estable "Release"
{% endhint %}

<figure><img src="/files/1lKL2bFf80UXDc9sBSAM" alt=""><figcaption></figcaption></figure>

4. **Flashea el firmware:** Haz clic en "Flash" y espera a que se complete el proceso.
5. **Explora las nuevas funciones:** Una vez finalizada la instalación, familiarízate con las características y configuraciones adicionales que ofrece Momentum.
